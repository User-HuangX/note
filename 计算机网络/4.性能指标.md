# 速率
信道：不等于通信线路，在逻辑上一条发送信道一条接受信道

速率是信道传输数据的速率，也还是比特率
bit/s b/s bps注意B和b的区别
数量前缀 K M G T 10^3

# 带宽
某个信道能传送的最高数据率/通过的频率的范围

几点间通信的最高速度由带宽，节点性能共同限制

# 吞吐量
实际通过数据量

# 时延 Delay

总时延 = 发生时延 + 传播时延 + 处理时延 + 排队时延

发生时延-上信道
传播时延-在信道上
处理时延-被路由器处理
排队时延-在路由器排队的时延

# 时延带宽积
发送出但是没有到达的比特


# 往返时延
游戏延迟，客户端到服务器往返总时长

# 信道利用率

有数据的时间/没数据的时间
ps:网络利用率，信道利用率的加权平均
